# 🌙 Bangladesh Ramadan Times

Welcome! This is a fun little web app I built to help people check Sehri and Iftar times for any district in Bangladesh during Ramadan. 

## ✨ What's This All About?

This is a hobby project that makes it super easy to find when to start and break your fast during Ramadan! Simply pick your division and district in Bangladesh, and boom - you'll see the exact Sehri (pre-dawn meal) and Iftar (breaking fast) times for your location.

Perfect for anyone observing Ramadan in Bangladesh, or just curious about prayer times across the country!

## 🎯 Features

- 📍 **All Bangladesh Districts** - Coverage for every district across all divisions
- 🕌 **Sehri & Iftar Times** - Clear display of pre-dawn and breaking fast times
- 🎨 **Clean Interface** - Simple, beautiful design that's easy to navigate
- ⚡ **Fast & Responsive** - Works smoothly on phones, tablets, and desktops


## 🛠️ Built With

This project was a great opportunity to work with some awesome modern technologies:

- **React** - For building a smooth, interactive UI
- **TypeScript** - Making JavaScript better with type safety
- **Vite** - Lightning-fast development experience
- **Tailwind CSS** - Quick and beautiful styling
- **shadcn/ui** - Pre-built, accessible UI components that look great

It's been a fun learning journey putting all these pieces together!
